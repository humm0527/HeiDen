# 02 数据目录

真实业务数据与计算结果仅保存在本地，不随源码提交。月度转换目录中的Python代码、测试和说明仍提交。

| 路径 | 用途 |
| --- | --- |
| `股票打分结果/` | 原始月度截面Excel |
| `single/` | 月度截面生成的逐日季度CSV；日期完整时快捷入口直接复用 |
| `月截面数据转化为逐日数据/` | 转换代码、测试、说明及本地日历；日历和转换记录不提交 |
| `risk_events/` | 风险股票拦截、风险股票分档使用的跨年度正式风险输入及ST证据，不能当作无用日志删除 |
| `集中度YYYYQn.csv` | 全行业季度分类及历史证券范围 |
| `return_prices/` | 本地收益行情及其来源清单 |
| `outputs/` | 独立运行02或风险股票拦截、风险股票分档时生成的结果 |

输入以本次运行选择为准，不固定引用旧批次。正式输入及其计算清单应配套保留；运行结束后的结果目录是否保留，由使用者决定。
