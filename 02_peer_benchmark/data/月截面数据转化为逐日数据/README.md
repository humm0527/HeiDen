# 月截面数据转化为逐日数据

将 `../股票打分结果/股票打分结果YYYYMMDD.xlsx` 的 `Sheet1` 展开成逐交易日数据，默认写入 `../single/集中度分类_YYYYQn.csv`。路径均相对于脚本位置，运行时不必切换工作目录。

## 日期规则

1. 文件名中的日期为截面日期。若为非交易日，连续向前回溯到最近交易日（同时处理周末及节假日）。
2. 首份截面从自身日期开始使用。后续截面从自身回溯日期的下一个交易日开始使用，直到下一份截面的回溯日期，包含该结束日。
3. 因此，2025-01-15 至 2025-02-28 使用 20250115 文件；2025-03-03 至 2025-03-31 使用 20250228 文件。
4. 例如 20250831 文件回溯至 2025-08-29，8月29日仍用 20250731 文件，9月1日开始使用 20250831 文件。
5. 缺月时延续上一份实际存在的截面。已确认：2026-06-01 至 2026-08-03 使用 20260529 文件；2026-08-04 至 2026-08-31 使用 20260803 文件。
6. 默认从首份文件的回溯日期输出到末份文件的回溯日期。因此，本次截止 2026-08-31，20260831 文件会被读取和校验，但本次尚无使用它的交易日。可通过 `--end-date` 指定更晚截止日，前提是同步更新交易日历。

## 输入和输出

- 输入使用 `Sheet1` 的 `证券代码、证券名称、集中度分类` 三列，不重新评分、不按历史文件覆盖分类。每个交易日完整复制该截面的股票池、名称及分类，并保留源文件中的股票顺序。
- 输出固定四列：`biz_date,stk_code,证券名称,券商03`。日期为 `YYYY-MM-DD`，证券代码保留前导零及 `.SH/.SZ/.BJ` 后缀，文件为 UTF-8 BOM、逗号分隔、CRLF 换行，与参考 CSV 格式一致。
- 按季度分文件，季度内日期升序。不补首份截面之前的日期，不补非交易日。
- 已确认空分类统一填 G，默认策略为 `g`。也可显式选择：`keep` 保留股票并留空；`drop` 删除该股票；`error` 遇空值报错。
- 源文件、`history_single` 模板保持原样。重复运行会替换本次涉及的同名季度 CSV，其他文件保留。若使用 `--start-date` 或 `--end-date` 缩小区间，建议同时指定独立的 `--output-dir`，避免将完整季度替换为部分季度。
- `last_run_manifest.json` 记录源文件哈希、回溯日期、生效区间、交易日数、股票数、空分类数、输出行数和输出哈希。明细置于脚本目录，输出目录只放目标 CSV。

## 交易日历

匿名源码包不附带交易日历或真实Excel。使用者应提供覆盖目标区间的交易日历，包含 `market_code,calendar_date,is_trading_day` 三列；不得用普通工作日代替交易日。

## 运行

需要 Python 3.10 或更新版本，依赖为 `openpyxl`（模块原有 requirements.txt 已包含）：

```bash
python3 -m pip install 'openpyxl>=3.1,<4'
python3 02_peer_benchmark/data/月截面数据转化为逐日数据/convert_monthly_to_daily.py
```

自定义参数示例：

```bash
python3 02_peer_benchmark/data/月截面数据转化为逐日数据/convert_monthly_to_daily.py \
  --input-dir 02_peer_benchmark/data/股票打分结果 \
  --output-dir 02_peer_benchmark/data/single \
  --blank-policy g \
  --end-date 2026-08-31
```

其他选项见 `--help`，包括 `--calendar`、`--start-date`、`--sheet`、`--market` 和 `--manifest`。

## 校验

程序在正式写出前校验所有源文件的文件名、必需列、证券代码格式、重复代码、名称及分类合法性；拒绝同一天出现多个回溯后的截面。

```bash
python3 -m unittest discover \
  -s 02_peer_benchmark/data/月截面数据转化为逐日数据 \
  -p test_conversion.py -v
```

测试覆盖首日和月末包含关系、周末及长假回溯、跨缺月区间、空分类策略、证券代码前导零、季度拆分、BOM 和 CSV 引号转义。Excel读取测试在临时目录生成虚构样例，不依赖外部业务文件。
