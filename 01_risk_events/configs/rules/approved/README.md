# Approved rules

正式业务计算未来只能从本目录加载规则。

当前依次保留 `rules_v1.yaml`、`rules_v2.yaml`、`rules_v3.yaml` 和 `rules_v4.yaml`。v1 冻结集中度业务初始设计；v2 只把事件字段迁移为 canonical `security_code`，并作为既有风险事件正式批次的规则证据；v3 按 D-063、D-064 关闭 Q-018，冻结预警天数、中文指标输出、命中率和预警率；v4 按 D-067 关闭 Q-019，冻结“周末分类行忽略且不截断连续危险轮次”。四个版本均不可覆盖；“规则已批准”不等于券商指标算法已实现或真实数据已运行。

风险事件历史复现继续显式读取 v2，后续券商指标显式读取 v4，并记录对应 SHA-256；不得从 `draft/` 回退。后续修改口径必须新增版本文件，禁止原地覆盖已经发布或执行过的规则版本。
