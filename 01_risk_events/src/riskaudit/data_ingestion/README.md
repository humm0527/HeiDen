# 代码实现层

本包仅实现文件/API 数据接入、不可变原始数据（Raw）持久化、配置驱动的字段映射、中文业务标准表、稳定的 Python 字段名以及数据血缘清单。

本包明确不包含数据预检分析、风险事件识别、券商效果指标计算、风险评分、Agent、前端和模型训练。

数据来源分为两条独立链路：`market_data/` 接收米筐等市场事实数据，只生成交易日历、证券基础状态日、股票日行情和证券风险状态四表；`business_input/` 接收券商CSV/Excel/JSON，只生成券商风险分类表。

米筐（RQData）接入提供 `MockRQDataClient` 和延迟导入 SDK 的 `RealRQDataClient`。真实客户端只读取 SDK 原生凭证 URI 环境变量或成对账号环境变量，不保存或输出凭证。停牌响应独立保存为 Raw。真实米筐烟测不再构造或输出券商分类。
